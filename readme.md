# EvOS

Evolution OS (EvOS) is an experimental operating system project.

The goal is not to recreate macOS and not to build another Linux distribution.

The project explores an alternative path for desktop computing based on the ideas of Darwin, OpenStep, GNUstep and workstation-oriented environments.

Initial targets:

* x86_64 architecture
* QEMU virtual machines
* Darwin/XNU research
* Open source userland
* GNUstep desktop technologies

The first milestone is simple:

A bootable system image that can start in QEMU, provide a shell, networking and a development environment.

Everything else comes later.
